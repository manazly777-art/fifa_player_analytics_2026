# FIFA Player Performance Analysis

## ⚽ Project Overview

An interactive Power BI dashboard analyzing FIFA player performance based on goals, assists, saves, positions, teams, clubs, and age groups.

## 🎯 Objective

The objective of this project is to analyze player performance and identify top contributors across attacking and goalkeeping metrics while exploring how performance varies by position, team, club, and age group.

## 🛠️ Tools & Skills

- Power BI
- Power Query
- Data Cleaning & Transformation
- DAX
- Data Visualization
- KPI Cards
- Interactive Slicers
- Dashboard Design
- Performance Analysis

## 📊 Dashboard KPIs

The dashboard provides four key performance indicators:

- **Total Goals**
- **Total Players**
- **Total Assists**
- **Total Saves**

These KPIs provide a quick overview of overall player performance in the dataset.

## 📈 Dashboard Visualizations

### Top 5 Goal Scorers
Identifies the five players with the highest number of goals.

### Top 5 Assisters
Highlights the five players with the highest number of assists.

### Top 5 Goalkeepers by Saves
Identifies the five goalkeepers with the highest number of saves.

### Goals by Position
A pie chart showing how goals are distributed across different player positions.

## 🎛️ Interactive Filters

Users can interact with the dashboard using slicers for:

- **Team**
- **Age Group**
- **Club**

These filters allow users to explore player performance across different teams, age categories, and clubs.

## 🔍 Key Analysis Areas

### Attacking Performance
Analyzed goals and assists to identify the leading attacking contributors.

### Goalkeeping Performance
Compared goalkeepers based on the number of saves recorded.

### Position Analysis
Examined how goals are distributed across different playing positions.

### Team & Club Comparison
Used interactive filters to explore performance across teams and clubs.

### Age Group Analysis
Explored player performance across different age categories.

## 💡 Key Insights

The dashboard enables users to identify:

- Top goal scorers and assist providers
- Goalkeepers with the highest number of saves
- Positions contributing the most goals
- Differences in performance across teams and clubs
- Performance patterns across different age groups
